# 🌊 Harbor – Skincare with Comfort

🌐 **Live Site:** [https://harbor-comfort.netlify.app](https://harbor-comfort.netlify.app)

**Harbor** is a clean, elegant skincare brand website designed to reflect simplicity, beauty, and wellness. Built with performance and aesthetics in mind, it offers a soothing digital experience just like the products it represents.

---

## 🧴 About the Project

The Harbor website presents skincare products in a modern, minimal, and user-friendly format. With a focus on smooth navigation and visual calmness, it mirrors the essence of a trusted, premium skincare brand — gentle, clean, and effective.

---

## ⚙️ Tech Stack

This project is built using the following modern frontend technologies:

- ⚡ **[Vite](https://vitejs.dev/)** – Fast and lightweight build tool
- 🧠 **[TypeScript](https://www.typescriptlang.org/)** – Strongly typed JavaScript
- ⚛️ **[React](https://reactjs.org/)** – Component-based UI library
- ✨ **[shadcn/ui](https://ui.shadcn.com/)** – Accessible and beautiful UI components
- 🎨 **[Tailwind CSS](https://tailwindcss.com/)** – Utility-first CSS framework for responsive design
